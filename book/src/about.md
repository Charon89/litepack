# About these docs

These pages are built from Markdown files committed to the LitePack repository (the `book/`
folder) and are rebuilt and published on every change to the `main` branch. The text you read is the
text in git; there is no other source.

The documentation is licensed under Apache-2.0 OR MIT, the same terms as LitePack's code. The
license texts are `LICENSE-APACHE` and `LICENSE-MIT` in the repository.
